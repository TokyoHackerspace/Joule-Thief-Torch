# Joule Thief

**English:** [README.md](./README.md)

パワーが弱くなってリモコンなどで使えなくなった単3・単4電池を、捨てるのがもったいないと思ったことはありませんか？

残っているエネルギーを最後の1ジュールまで、何か（ほんの少しでも）役に立つことに使えたらと思いませんか？

そんなときに使えるのが、Joule Thief（ジュール・シーフ：エネルギー泥棒）懐中電灯です！

![9 JT test](./images/9-JT-test.jpg)

## はじめに

Joule Thief回路は、使い捨て電池に残っているエネルギーをほぼ最後まで取り出すための回路です。コイルに磁界としてエネルギーを蓄え、トランジスタを使ってそのエネルギーをLEDへ放出し、また最初から繰り返すことで動作します。そのため、LEDに連続して電力を供給しているわけではありません。実際にはLEDを非常に高速で点滅させています（通常は人間の目では気付かないほど高速です）。コイルは機械的な振動を伴うことがあるため、人によってはコイルが「鳴っている」ように聞こえることがあります。

この回路では、共通のコアに2つのコイルを巻きます。2つは互いに逆向きになるよう配線されており、一次側のコイルに磁界が蓄えられるにつれて、もう一方のコイルにも誘導電圧が生じます。そして電圧が十分高くなると、トランジスタが動作します。抵抗は充電の進み方を緩やかに調節し、トランジスタがすぐにスイッチしてしまうのを防ぎます。

トランジスタがスイッチすると、そのコイルに蓄えられていた磁界が崩壊し、隣のコイルに強いパルスが誘起されます。これにより、LEDへ送られる出力電圧は電池そのものの電圧よりもかなり高くなります。

## 部品

![1 JT parts layed out](./images/1-JT-parts-layed-out.jpg)

袋を開け、部品をひとつずつ確認しながら並べてみましょう。

- まず、黄色いPCB（プリント基板）があります。両面を確認してください。クレジット表記がある側が裏面で、各部品の外形が印刷されている側が表面です。すべての部品は表面側から差し込み、裏面側ではんだ付けします。
- 次に、電池ケースがあります。ケースの内側をよく見て、`+` と `-` の表示を確認してください。基板に取り付ける向きが重要です。PCB上の向きと照らし合わせて確認してください。
- 3本の端子と2つの金属製タブが付いた四角い金属部品が電源スイッチです。黒いスイッチのつまみが外側へ出るように、基板右端に取り付けます。
- 3本の端子が付いた黒い部品がトランジスタです。片側が丸く、反対側が平らになった形をしています。PCB上にも同じ形が描かれているので、向きを間違えないよう確認してください。
- 2本の長い金属線の間に茶色（青色の場合もあります）の筒が付いている細長い部品が抵抗です。抵抗には向きがないので、どちら向きに取り付けてもかまいません。PCB上には長方形で取り付け位置が描かれています。
- 最後に、下側から2本の端子が出ている透明な部品が2つあります。これがLEDです。LEDの根元には透明な縁取りがあります。指でつまんで回してみると、一部が平らになっているのが分かります。基板の端に描かれたLEDの円形表示にも、同じように平らな部分があります。

## 組み立て手順

小さく背の低い部品から始めて、大きく背の高い部品へ進む順番ではんだ付けすることをおすすめします。そのため、Joule Thiefは通常、次の順番で組み立てます。

1. 抵抗
2. スイッチ
3. LEDを曲げて、はんだ付けする
4. トランジスタ
5. 電池ケース
6. コイルを加工する
7. コイルをはんだ付けする
8. Joule Thiefをテストする（必要なら修理する）
9. 結束バンドでコイルを固定する

完成！

### コイルを加工する

![JT coil 1](./images/JT-coil-1.jpg)

上の写真は、キットに付属するコイルの一例です。白いトロイダルコアに銅線が巻かれています。もう少し大きい緑色のトロイダルコアが入っている場合もありますが、どちらでも同じように使えます。

この状態では、コイルは1つだけで、トロイダルコアから2本の線が出ています。これを加工し、2つのコイル、つまりトロイダルコアから4本の線が出る状態にします。

![JT coil 2](./images/JT-coil-2.jpg)

まず、銅線をトロイダルコアからすべてほどき、写真のような状態にします。  
片方の線を中央の穴へ慎重に押し込み、そのまま引き抜くようにするとほどきやすいです。完全にほどけるまで繰り返してください。

![JT coil 3](./images/JT-coil-3.jpg)  
できるだけ銅線をまっすぐに伸ばします。中央を見つけて、線を半分に切ってください。  
線の両端をよく見てください。片方は、絶縁用のエナメル被膜がすでに除去されているため光沢があります。反対側はオレンジ色の被膜が残っています。

2本の線を並べます。必要なら片方の線の向きを反転させ、両側それぞれに「光沢のある端」と「エナメル被膜のある端」が1本ずつ来るようにしてください。この違いを目印にすることで、巻き方を正しく保ち、PCBの正しい位置へはんだ付けしやすくなります。

![JT coil 4](./images/JT-coil-4.jpg)

コイルを巻き始めるところは特に重要なので、焦らず慎重に作業してください。  
2本の線をそろえて持ち、その片側をトロイダルコアの穴へ通します。上の写真のように、線がコアへ引っ掛かる形になるよう曲げます。このとき、端に「光沢のある線」と「エナメル被膜のある線」が1本ずつあることをもう一度確認してください。

![JT coil 5](./images/JT-coil-5.jpg)

2本の線をきれいに並べ、再びトロイダルコアの穴へ通します。線同士が交差しないよう、時間をかけて整えてください。最初の1〜2巻きが終わったあとは、1本ずつ穴へ通した方が作業しやすいこともあります。

巻くときは、線がトロイダルコアへしっかり密着するように強めに引っ張ってください。完璧である必要はありませんが、丁寧に整えるほど見た目がきれいになり、性能もごくわずかに良くなるかもしれません。

![JT coil 6](./images/JT-coil-6.jpg)

銅線をすべてトロイダルコアへ巻き切る必要はありません。終わりに近づいたら、最後の1〜2巻き分の空間を確保できるよう、それまでの巻き線の間隔を少し詰めてください。  
トロイダルコアの両側には、それぞれ2本ずつの線が出ています。そのうち1本は光沢があり、もう1本はエナメル被膜で覆われています。また、たとえば光沢のある線同士が対角線上に位置していることも確認してください。

### コイルをはんだ付けする

![JT coil 7](./images/JT-coil-7.jpg)

コイルの線をPCBへ差し込む作業は少しやりにくいかもしれません。重要なのは、エナメル被膜のある線同士が対角線上に来て、光沢のある線同士がもう一方の対角線上に来るようにすることです。

![JT coil 8](./images/JT-coil-8.jpg)

コイルを基板の近くまでしっかり収めるには、表面側から線の形を整えながら、PCBの裏側から線を引っ張ると作業しやすくなります。

エナメル被膜のある線をはんだ付けするときは、さらにひと手間必要です。通常より長めに、熱したはんだごての先端を線へ当て、エナメル被膜を焼き切る必要があります。そのあとではんだを流してください。加熱時間が短すぎると、はんだが線へ付きません。その場合は、はんだと線へもう一度こて先を数秒間当て、被膜が除去されてはんだがなじむまで加熱してください。

### Joule Thiefをテストする（必要なら修理する）

ここで電池を入れ、Joule Thiefをテストしてみましょう。スイッチをONにしてください。LEDが点灯しない場合は、はんだ付け部分をもう一度確認してください。特にコイル周辺をよく確認します。また、LEDの平らな部分の向きがPCB上の表示と一致していることも確認してください。

### 結束バンドでコイルを固定する

![8 JT zip tie](./images/8-JT-zip-tie.jpg)

問題なく動作したら、PCBの穴へ結束バンドを通し、コイルをしっかり固定しておくとよいでしょう。緩まない程度に締めますが、締めすぎないようにしてください。最後に余った部分を切り落とします。

## オシロスコープで出力を見る

興味があれば、オシロスコープを使ってLEDへ送られている出力電圧を観察できます。オシロスコープのグランドクリップは、スイッチの金属ケース部分、または電池ケースのばね状端子へ接続できます。

プローブの先端は、LEDの平らな部分とは反対側の端子へ接続してください。

オシロスコープの「Auto」ボタンを押すか、下の写真のような波形が見えるまで設定を調整してください。

![JT scope](./images/JT-scope.jpg)

この波形では、横軸の時間が1目盛りあたり1マイクロ秒（µs）、縦軸の電圧が1目盛りあたり1ボルトです。したがって、充電とパルスの1サイクルは約3マイクロ秒で、パルスのピークは4ボルト程度だと分かります。また、少なくとも1 µsの間、2.5ボルト以上を維持しています。

この波形は、電池のエネルギーが消費されるにつれて常に変化していきます。パルスの持続時間も、出力電圧全体も変化することがあります。電池のエネルギーが減るにつれ、パルスとパルスの**間隔**は次第に長くなります。やがて電池の残量がほとんどなくなる頃には、LEDのちらつきが目で分かるようになることもあります。
